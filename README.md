# Web Dev CRM & Client Pipeline Dashboard

Dashboard CRM dedicat pentru gestionarea clienților de site-uri web (Marius & Mara, Miruna, Edi & Simina, Bogdan, Eden), cu urmărirea automată a etapelor (Lead, Ofertat, În Lucru, Finalizat), calculul valorii totale a pipeline-ului și adăugarea de clienți noi.

## Cum rulezi proiectul
- **Vizualizare Imediată:** Fă dublu-click pe `index.html` pentru a deschide panoul de control în browser.
- **Hosting Live:** Încarcă fișierele (`index.html`, `styles.css`, `app.js`) pe Cloudflare Pages sau Vercel.
